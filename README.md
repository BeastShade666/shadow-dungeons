# Shadow Dungeons

A first playable, mobile-friendly third-person 3D dungeon prototype.

## Play

Enable **Settings → Pages → Build and deployment → Deploy from a branch**, select **main** and **/(root)**, then Save. After deployment, open https://beastshade666.github.io/shadow-dungeons/ on Android or desktop. You can add the site to your home screen through your browser menu.

## Controls

- Desktop: WASD / arrow keys to move; Space to attack.
- Android: on-screen directional buttons and ATTACK.

## Included

- 3D third-person arena and follow camera
- Enemy pursuit, attacks, damage and defeat
- Progressively harder floors and a stronger enemy type every third floor
- Gold drops, lobby cosmetics shop, hero color selection
- Local save for gold and purchased aura

## Notes

The prototype uses Three.js from a CDN, so the first load requires internet. It is not yet a native Android APK or offline-capable PWA. This is a browser prototype, not a Godot export. The game has not yet been verified in a live mobile browser; please report issues with device/browser details.
